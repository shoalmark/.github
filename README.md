# .github

The shoalmark organization's profile. The page at [github.com/shoalmark](https://github.com/shoalmark) shows `profile/README.md` from this repository.

This repository holds nothing else on purpose: GitHub lends the community files of an organization's `.github` repository, such as a security policy or contributing guide, to every repository of the organization that lacks its own. Each shoalmark repository keeps its own.
